## English

A Pi-based terminal workspace for AI-assisted programming with its own identity. It organizes projects and work items with independent sessions and, when Git is available, branches and worktrees.

**Status:** product definition. There is no implementation or installation procedure yet.

The bilingual documentation index above links every document and its translation. Each ES/EN pair shares a stable number. Files use `NN-topic.md`; this README is the main index. Notion will preserve the same numbering. Notion publication: **pending confirmation**.

Development will proceed in small stages: agree on scope, implement, verify, review, and document in Spanish and English. Optional Forge614-Engram integration will be addressed last.
