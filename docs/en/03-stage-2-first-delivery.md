# 03 — Historical record: first Stage 2 delivery

Like a construction-site photograph, this document preserves an earlier moment without confusing it for the finished building.

The first Stage 2 delivery created the TypeScript/Bun launcher, the initial Pi integration, and the terminal-interface foundation. It is a historical record, not a guide to current capabilities.

Claims about engines in earlier deliveries may have changed. Gemini and Antigravity, in particular, were removed; [04](04-architecture-engines.md) is the current architecture and engine reference. Engram initialization and its follow-up MCP configuration live in [07](07-engram-initialization-and-mcp.md).

Current verification, versions, and counts are published in the README and documents 04, 06, and 08.
